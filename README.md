# 🖥️ codeRume

## This is a real-time code collaboration platform for rookies and savants to intermingle, learn together and share.
*codeRume* utilizes *pusherJS* for real-time communication between coders, *Clerk* for auth, *codemirror* and *liveblocks* for a seamless integrated development environment and *NeonDB* to host relational app and user data. I've also created simple animations using *Framer Motion*, with *nodemailer* allowing for email notifications.

 ## ⚙️ Tech Stack
| **Layer**          | **Technology**             |
|---------------------|----------------------------|
| Language    | Typescript      |
| Framework    | Next.js      |
| Styling & Animations    | TailwindCSS, Framer Motion      |
| State Management    | Zustand      |
| Storage    | PostgreSQL hosted on NeonDB      |
| Auth   | Clerk     |

## 🚀 Getting Started
### :one: Clone and install
```
git clone https://github.com/aLearningLad/codeRumeV2.git
cd codeRumeV2
npm install
```

### :three: Run Locally
```
npm run dev
```

# 🧠 Lessons & Takeaways
