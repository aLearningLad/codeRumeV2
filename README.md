# 🖥️ codeRume

## This is a real-time code collaboration platform for rookies and savants to intermingle, learn together and share.
It utilizes *pusherJS* for real-time communication between coders, *Clerk* for auth, *codemirror* and *liveblocks* for a seamless integrated development environment and *NeonDB* to host a postgreSQL table. I've also created simple animations using *Framer Motion*, with *nodemailer* allowing for email notifications.
